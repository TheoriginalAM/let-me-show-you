# Fonts

Bundled so the app looks right offline. Both are variable fonts from Google Fonts,
subset to Latin and Latin Extended, and licensed under the SIL Open Font License 1.1
(https://openfontlicense.org).

- **Anybody** (display; weight 100 to 900, width 50% to 150%). Copyright The Anybody Project Authors (https://github.com/Etcetera-Type-Co/Anybody).
- **Hanken Grotesk** (text; weight 100 to 900). Copyright The Hanken Grotesk Project Authors (https://github.com/marcologous/hanken-grotesk).
